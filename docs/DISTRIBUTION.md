# Distribution

## Channel strategy

Evenward separates product discovery, product delivery, technical review, and
identity:

| Address | Role |
| --- | --- |
| `evenward.rest` | Application on Neocities |
| `docs.evenward.rest` | Documentation through GitHub Pages |
| `github.com/howardhayden/evenward` | Source, tests, issues, and version history |
| `evenward.neocities.org` | Neocities-native discovery address |

The independent domain preserves product identity if the underlying host
changes.

## Why Neocities

Neocities gives Evenward a culturally coherent early-adopter position:

- independent web;
- human-scaled technology;
- resistance to platform extraction;
- creative experimentation;
- alignment with the “Small, Open Places” philosophy.

This is product-channel alignment, not an assertion that the Neocities audience
represents the whole market.

## Why GitHub

GitHub provides:

- inspectable source and version history;
- issue-based feedback;
- visible testing and engineering decisions;
- conventional technical evaluation;
- documentation hosting separate from the consumer application.

The combination makes the distribution choice legible: Neocities reaches an
aligned community; GitHub supports governance and review.

## Initial segment

Likely early adopters value independent software, privacy, accessibility,
creative web design, learning, and alternatives to extractive wellness
platforms.

The early goal is to test resonance, vocabulary, navigation, trust, and
movement interest within a concentrated audience before broader distribution.

## Measurement

Evenward ships without behavioral analytics. Initial evidence should come from:

- voluntary feedback;
- issue reports;
- small moderated usability sessions;
- public repository engagement;
- aggregate counts disclosed by infrastructure only when they do not expose
  individual behavior.

Any future measurement must be optional, proportionate, documented, and
consistent with the privacy architecture.

## Operational trade-offs

- Static hosting reduces cost and operational complexity but excludes
  server-side accounts and synchronization.
- Browser storage preserves privacy but does not follow users across devices.
- A niche discovery channel improves alignment but limits initial reach.
- Public source increases accountability while making execution quality—not
  feature secrecy—the primary defense.
