# Product

## Product thesis

Evenward is not a collection of unrelated wellness exercises. Its product
theory is:

> Regulation is the practiced ability to move toward a more workable state
> through body, attention, pattern, knowledge, and play.

The product loop is:

1. notice the present state;
2. select a direction;
3. complete a small practice;
4. observe what changed.

The application never claims to detect a state or select the correct direction.

## Directional model

Evenward supports several user-chosen intentions:

- **Downregulating:** reduce demand, slow pace, or make quiet more approachable.
- **Upregulating:** invite energy, range, orientation, or alertness.
- **Gathering attention:** stay with a bounded object or position.
- **Moving:** use structured motion before or instead of stillness.
- **Observing:** gather information without assigning meaning.

No direction is scored as better, healthier, or more successful. A user can
pause, change direction, or leave.

## Feature roles

| Feature | Product role |
| --- | --- |
| Tai chi and other movement | Structured, repeatable embodied attention |
| Breathing and sensory orientation | Short directional practices |
| Chess | Calm, bounded attention and staying with a position |
| Pattern exercises | Noticing relationships without immediate interpretation |
| Systems literacy | Clear explanations of choice, uncertainty, and evidence boundaries |
| Trainer | Continuity, instruction, access adaptation, and responsive presence |
| Care reference | Literal, interruptible material-care sequencing without physical-outcome inference |

Chess belongs because it practices remaining with a position, not because the
application assigns it a health effect. Literacy reduces helplessness by
making choices legible without claiming diagnostic certainty.

## Audience and value

The initial audience values:

- privacy-conscious software;
- independent-web culture;
- accessible and interruptible practice;
- expressive interfaces without extractive engagement systems;
- learning and agency rather than passive content consumption.

Evenward avoids streaks, urgency, social comparison, biometric surveillance,
and inspirational-pressure language.

## Product and business decisions

- A web application lowers installation friction and supports independent
  distribution.
- A static architecture keeps hosting inexpensive, portable, and inspectable.
- Browser-only persistence supports continuity without accounts.
- Neocities is an early-adopter discovery channel rather than a total market.
- GitHub provides source governance, technical evaluation, and documentation.
- A host-independent domain preserves identity if infrastructure changes.

Defensibility comes from integrating movement, attention, pattern, literacy,
privacy, and access into one coherent loop—not from any single feature.

## Evaluation hypotheses

Without behavioral tracking, the project can test:

- whether visitors voluntarily explore more than one practice;
- whether privacy and accessibility documentation supports trust;
- whether trainer customization creates an understandable entry point;
- whether systems literacy supports voluntary return;
- whether technical reviewers inspect architecture and tests.

Evidence can come from optional feedback, issue reports, public repository
activity, and small moderated usability sessions. No hidden analytics are
required.

## Non-goals and boundaries

Evenward is not:

- medical or mental-health care;
- diagnosis, assessment, crisis support, or treatment;
- an authority on a user’s emotional state;
- a biomechanical evaluation tool;
- a replacement for qualified movement instruction;
- a social network or quantified-self platform.

The footwear-care reference supports only explicitly confirmed black, smooth,
finished leather and the registered Saphir Amiral Gloss profile. It does not
identify a material, measure physical coverage, assess damage, certify a
finish, or replace the maker's current directions and warnings.

If a practice feels painful, destabilizing, or unsuitable, the user should
stop. The application cannot evaluate individual safety.
