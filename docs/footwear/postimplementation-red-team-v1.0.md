# Leather Footwear and Polish - Postimplementation Red Team

Date: 2026-09-01

Subject: executable reference implementation against `requirements-v1.2-current.jsonl`

Verdict: **FAIL - corrected reference remains ineligible for production**

Claim boundary: **zero Verified requirements; `productionUnlocked` remains `false`**

This is an additive failure record. It does not replace the [preimplementation red team](preimplementation-red-team-v1.0.md), either care-addendum candidate, or any earlier register. A correction below means that a reproduced software defect was removed from the reference implementation. It does not mean that the associated requirement is Verified.

## Denominator and decision

The v1.2 register contains 137 unique requirements: 95 `candidate-required` rows and 42 `inherited-blocker` rows. The postimplementation red team found executable mechanisms worth retaining, defects that were corrected, and production claims that the reference still cannot support. The release decision therefore remains **FAIL**.

The reference may be used to exercise care semantics, failure handling, material-control conversion, and a locally generated procedural WebGL presentation. It may not be described as canonical admission, an authored production shoe, measured physical contact, a conforming optical renderer, a device-qualified accessible experience, or a released Evenward implementation.

## Residual blockers after correction

These are not deferred polish items. Each prevents a production or compliance claim:

1. **Authority and admission:** canonical addendum admission and recomputation of all source-byte pins remain external release work; the dated product URLs are mutable references, not immutable content pins.
2. **Authored geometry and contact:** production shoe assets, stable pivots and sole markers, measured silhouette/normals, production cloth-to-surface anchors, and 8–18 mm / 3–5 Hz executed kinematics are absent; procedural numeric placement does not replace them.
3. **Optical pipeline:** preserved raw mip 0, confidence-weighted near-field reflection, full box projection, revision-atomic six-face transactions, invalidation, tier residency, and production GPU output evidence are absent. The local sentinel is only a basic fail-closed output check.
4. **Whole-product propagation:** both shoes across every movement, view, seated state, adaptation, compact/primary/peer/fallback consumer, theme, mode, tier, and backend have not been enumerated and tested.
5. **Optical and temporal QA:** mask denominators, glint metrics, scene-recognition coverage, adjacent-tier SSIM, landmark error, chroma, luma stability, and trail limits have no independent rendered evidence.
6. **Accessibility and devices:** keyboard, touch, switch, voice, focus, announcements, browser zoom, low vision, forced colors, screen readers, context loss, and supported device/backend soaks have not been executed.
7. **Performance and privacy observation:** frame-cost budgets, three 180-second runs, storage inspection, and network observation remain unevidenced on the supported matrix.
8. **Independent review:** source regexes, DOM labels, unit tests, and this report cannot certify mechanisms that require measured pixels, geometry, contact, devices, or human comprehension.

The postimplementation report, implementation evidence map, and later ledger entries are additive working-tree evidence but are not themselves hash-pinned by the v1.2 register. Their review and preservation remain an external evidence-custody obligation.
